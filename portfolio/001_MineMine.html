Project Mine Mine

Program Game

Project Overview

2D Platformer Arcade Mining game with a limit of time.

Key Contribution

  • I have created the core gameplay mechanics, including player movement, mining systems, and a game timer.
  • I also implemented a multi-level system with varying map sizes and mineable materials.
  • Furthermore, I completed the game settings, file-based data saving, and a shop system.

Reflection

I was able to incorporate all the features that I felt were fundamentally essential for a game.

Personally, I consider this to be one of the most polished games I have created to date. I received feedback suggesting that a minimap would be a welcome addition

I hope to eventually rebuild this game using Unity or Unreal Engine so that I can implement that feature.
